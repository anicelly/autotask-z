# ⚡ AutoTask Z

Sistema de automação de tarefas inspirado em estética retrô gamer/anime dos anos 90.

Projeto desenvolvido com:

- HTML5
- CSS3
- JavaScript
- Chart.js
- Kanban Drag and Drop
- Dark Mode
- Dashboard Inteligente
- Notificações do Navegador
- Responsividade
